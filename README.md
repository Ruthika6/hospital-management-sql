# Hospital Management & Analytics System (SQL)

## Description
This project implements a Hospital Management and Analytics System using MySQL.
It focuses on database design, normalization, and advanced SQL analytics.

## Features
- Normalized relational database design
- Foreign key constraints for data integrity
- Advanced SQL queries using JOINs, subqueries, CTEs, and window functions
- Revenue and patient analytics

## Technologies Used
- MySQL
- MySQL Workbench

## Key SQL Concepts
- JOINs
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregation and HAVING
